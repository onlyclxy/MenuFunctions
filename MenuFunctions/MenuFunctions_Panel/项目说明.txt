  右键菜单配置编辑器 - MenuFunctions_Panel
═══════════════════════════════════════════════════════════

【项目简介】
这是一个 WPF 可视化工具，用于编辑 SharpShell 右键菜单的 JSON 配置文件。
替代手动编写 JSON，提供类似 PC Quicker 的友好编辑界面。

【主要文件】
├─ MenuFunctions_Panel.exe       主程序
├─ Newtonsoft.Json.dll            JSON 处理库
├─ README.md                      完整功能说明
├─ 快速入门.md                     快速上手指南
└─ 示例配置.json                   示例配置文件

【技术架构】
- 框架：WPF + .NET Framework 4.8
- 模式：MVVM (Model-View-ViewModel)
- 依赖：Newtonsoft.Json 13.0.3

【核心功能】
✓ 可视化编辑 JSON 配置
✓ 树形显示菜单结构
✓ 支持多级子菜单
✓ 拖拽式排序（上移/下移）
✓ 文件浏览器集成
✓ 自动加载配置
✓ 实时预览和保存

【界面特色】
参考 PC Quicker 风格：
- 左侧：树形菜单结构
- 右侧：详细配置面板（分组折叠）
- 顶部：工具栏（常用操作）
- 底部：状态栏（当前文件）

【配置项支持】
完整支持 MenuItemConfig 的所有属性：
□ 基本信息：文本、可见性、排序
□ 显示位置：文件/文件夹/背景/根菜单
□ 程序设置：路径、参数、图标
□ 文件类型：扩展名过滤
□ 高级选项：引号、参数方式
□ CMD 设置：隐藏窗口、保持打开

【使用流程】
1. 运行程序 → 自动加载或手动打开配置
2. 编辑配置 → 使用图形界面修改
3. 保存文件 → 生成格式化的 JSON
4. 应用配置 → 复制到 DLL 目录，重启资源管理器
