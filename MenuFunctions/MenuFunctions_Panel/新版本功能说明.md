## 🆕 核心新功能

### 1. 📁 左侧文件浏览器
**用途：** 测试菜单命令时选择文件/文件夹

#### 功能按钮：
- **❌ 取消选择** - 清空当前选择
- **📂 选择文件夹背景** - 选择一个文件夹作为背景测试
- **🖥️ 选择桌面** - 快速选择桌面
- **🔄 刷新** - 刷新文件树

#### 使用方法：
1. 在文件树中点击选择文件或文件夹
2. 配合"测试运行"功能使用
3. 模拟真实右键菜单场景

### 2. 📋 复制/剪切/粘贴功能
完整的剪贴板操作，快速复制菜单配置

#### 操作方式：
**工具栏按钮：**
- 📄 复制 - 复制选中的菜单项
- ✂️ 剪切 - 剪切选中的菜单项
- 📋 粘贴 - 粘贴到选中项下

**右键菜单：**
- 复制 (Ctrl+C)
- 剪切 (Ctrl+X)
- 粘贴 (Ctrl+V)
- 在前面粘贴 - 插入到选中项前面
- 在后面粘贴 - 插入到选中项后面

**键盘快捷键：**
- `Ctrl+C` - 复制
- `Ctrl+X` - 剪切
- `Ctrl+V` - 粘贴
- `Ctrl+S` - 保存配置
- `Del` - 删除

#### 使用场景：
```
1. 复制现有菜单项，修改部分配置创建新项
2. 移动菜单项到不同位置（剪切 + 粘贴）
3. 批量创建相似的菜单项
```

### 3. 👁️ 启用/停用功能
快速切换菜单项的显示状态

#### 操作方式：
- 工具栏按钮："👁️ 启用/停用"
- 右键菜单："启用/停用"

#### 效果：
- 切换 `IsVisible` 属性
- 停用的菜单项会在树中显示 **[隐藏]** 标记

### 4. ▶️ 测试运行功能
在编辑器中直接测试菜单命令是否正常工作

#### 使用步骤：
1. 在左侧**文件浏览器**中选择测试文件/文件夹
2. 在中间**菜单树**中选择要测试的菜单项
3. 点击 **"▶️ 测试运行"** 按钮
4. 确认执行信息后点击"是"

#### 测试场景：
```
场景1：测试"用记事本打开"
1. 选择一个 .txt 文件
2. 选择"用记事本打开"菜单项
3. 点击测试运行
4. 验证是否正确打开记事本

场景2：测试文件夹命令
1. 点击"选择文件夹背景"
2. 选择一个测试文件夹
3. 选择"在此处打开CMD"菜单项
4. 点击测试运行
5. 验证CMD是否在正确路径打开
```

### 5. 🖱️ 右键菜单
在菜单树上右键点击，快速访问常用操作

#### 菜单项：
- 复制 (Ctrl+C)
- 剪切 (Ctrl+X)
- 粘贴 (Ctrl+V)
- 在前面粘贴
- 在后面粘贴
- ─────────
- 启用/停用
- 测试运行
- ─────────
- 删除 (Del)

## 📋 完整操作流程示例

### 示例1：创建并测试新菜单项

```
步骤1：创建菜单项
1. 点击"➕ 新增菜单项"
2. 填写菜单文本："用VSCode打开"
3. 填写程序路径："C:\Program Files\Microsoft VS Code\Code.exe"

步骤2：配置显示位置
1. 勾选"显示在文件上"
2. 填写文件类型：.txt, .js, .py

步骤3：测试运行
1. 在文件浏览器中选择一个 .txt 文件
2. 选中"用VSCode打开"菜单项
3. 点击"▶️ 测试运行"
4. 验证是否正确打开VSCode

步骤4：保存配置
1. 点击"💾 保存"
2. 确认保存成功
```

### 示例2：复制修改创建相似菜单

```
场景：已有"用记事本打开"，想创建"用写字板打开"

步骤1：复制现有配置
1. 选中"用记事本打开"
2. 按 Ctrl+C 或点击"📄 复制"

步骤2：粘贴并修改
1. 按 Ctrl+V 或点击"📋 粘贴"
2. 修改菜单文本："用写字板打开"
3. 修改程序路径："C:\Windows\write.exe"

步骤3：测试保存
1. 测试新菜单项
2. 保存配置
```

### 示例3：重新组织菜单结构

```
场景：将多个文本编辑器菜单整理到子菜单

步骤1：创建父菜单
1. 新增菜单项："文本编辑器"
2. 不填写程序路径（作为容器）

步骤2：移动现有菜单
1. 选中"用记事本打开"
2. 剪切 (Ctrl+X)
3. 选中"文本编辑器"
4. 粘贴 (Ctrl+V)
5. 重复移动其他编辑器菜单

步骤3：调整顺序
1. 使用"⬆️ 上移"/"⬇️ 下移"
2. 或使用右键菜单的"在前面/后面粘贴"
```

## ⚠️ 注意事项

### 测试运行
- 测试运行不会记录到Windows注册表
- 仅在编辑器中模拟执行
- 实际使用需要保存配置并重新注册SharpShell

### 文件浏览器限制
- 每个文件夹最多显示50个项目（性能优化）
- 隐藏文件不显示
- 某些系统文件夹可能无法访问

### 复制粘贴
- 复制会创建副本（名称加"副本"）
- 剪切会移动原项（执行粘贴后原项会被删除）
- 粘贴到子项：选中目标父项后粘贴
- 粘贴到同级：使用"在前面/后面粘贴"
