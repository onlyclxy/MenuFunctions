# 快速入门指南

## 第一次使用

### 1. 启动程序
运行 `MenuFunctions_Panel.exe`，程序会自动尝试加载配置文件。

### 2. 加载示例配置
如果自动加载失败，点击工具栏的 **📂 打开** 按钮，选择：
- `示例配置.json` - 查看示例
- 或你的 `MenuConfig.json` 文件

### 3. 界面介绍

## 常见操作

### 添加新菜单项

1. 点击 **➕ 新增** 按钮
2. 在右侧面板编辑配置：
   - **菜单文本**：输入显示名称，如"用记事本打开"
   - **程序路径**：点击"浏览..."选择程序，如 `notepad.exe`
   - **图标路径**：选择图标文件（可选）
3. 设置显示位置（勾选需要的选项）
4. 点击 **💾 保存**

### 创建子菜单

1. 在左侧树中选择父菜单项
2. 点击 **📑 添加子项** 按钮
3. 编辑子菜单的配置
4. 重复此过程可创建多级菜单

### 调整顺序

1. 在左侧树中选择要移动的菜单项
2. 点击 **⬆️ 上移** 或 **⬇️ 下移** 按钮
3. 同级菜单项会按 Order 字段排序

### 添加分隔线

点击 **➖ 分隔线** 按钮即可添加一个菜单分隔线。

### 删除菜单项

1. 选择要删除的菜单项
2. 点击 **🗑️ 删除** 按钮
3. 确认删除

## 实用技巧

### 💡 技巧 1：复制路径到剪贴板

```json
{
  "Text": "复制路径",
  "ProgramPath": "copypath",
  "ShowInRootMenu": true
}
```

- **ProgramPath** 设为 `copypath`（预设命令）
- 勾选"显示在根菜单"可直接显示在右键菜单顶层

### 💡 技巧 2：用特定程序打开文件

```json
{
  "Text": "用记事本打开",
  "ProgramPath": "notepad.exe",
  "FileTypes": [".txt", ".log", ".ini"],
  "ShowOnFiles": true,
  "ShowOnFolderBackground": false
}
```

- 指定文件类型，只在 .txt/.log/.ini 文件上显示
- 不在文件夹背景显示

### 💡 技巧 3：在当前文件夹打开 CMD

```json
{
  "Text": "在此处打开命令窗口",
  "ProgramPath": "cmd.exe",
  "ShowOnFolderBackground": true,
  "ShowOnFolder": true,
  "ShowOnFiles": false
}
```

- 只在文件夹和文件夹背景显示
- 不在文件上显示

### 💡 技巧 4：执行批处理脚本

```json
{
  "Text": "运行清理脚本",
  "ProgramPath": "C:\\Scripts\\cleanup.bat",
  "RunningProgramWithCMD": true,
  "HideCmdWindow": true,
  "ShowOnFolderBackground": true
}
```

- 通过 CMD 运行批处理
- 隐藏 CMD 窗口，后台执行

### 💡 技巧 5：使用动态变量

```json
{
  "Text": "重命名 ${filename}",
  "ProgramPath": "MyRenamer.exe"
}
```

菜单文本会动态显示为"重命名 文件名"。

支持的变量：
- `${filename}` - 文件名（无扩展名）
- `${extension}` - 扩展名
- `${fullpath}` - 完整路径
- `${parentdir}` - 父目录

## 配置检查清单

保存前请确认：

- ✅ 菜单文本已填写
- ✅ 程序路径正确（或使用预设命令）
- ✅ 显示位置至少勾选一项
- ✅ 如果有文件类型限制，格式正确（如 `.txt`）
- ✅ 图标路径正确（可选）

## 应用配置

1. 保存 `MenuConfig.json` 到：
   ```
   MenuFunctions\bin\Release\MenuConfig.json
   ```

2. 如果是新配置，需要重新注册 SharpShell：
   ```powershell
   # 注册（管理员权限）
   regasm /codebase MenuFunctions.dll
   srm install MenuFunctions.dll
   ```

3. 如果只是修改配置，重启资源管理器即可：
   ```powershell
   # 重启资源管理器
   taskkill /f /im explorer.exe
   start explorer.exe
   ```

## 故障排除

### 问题：无法加载配置文件
- 检查文件是否为有效的 JSON 格式
- 使用 JSON 验证工具检查语法

### 问题：修改后不生效
- 确保配置文件保存在正确位置
- 重启资源管理器
- 检查 DLL 是否正确注册

### 问题：菜单项不显示
- 检查"是否可见"选项是否勾选
- 检查显示位置设置是否正确
- 检查文件类型过滤是否过于严格
