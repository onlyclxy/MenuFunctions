# 右键菜单配置编辑器

这是一个用于可视化编辑 SharpShell 右键菜单配置的 WPF 工具。

## 功能特性

- ✅ **可视化编辑**：通过图形界面编辑 JSON 配置，无需手动编写
- ✅ **树形结构**：清晰显示菜单层级结构，支持子菜单
- ✅ **拖拽排序**：使用上移/下移按钮调整菜单项顺序
- ✅ **完整配置**：支持所有配置选项，包括显示位置、CMD 设置等
- ✅ **文件浏览**：集成文件浏览器，方便选择程序和图标
- ✅ **自动加载**：启动时自动查找并加载配置文件

## 界面布局

### 顶部工具栏
- 📂 **打开**：打开现有的 MenuConfig.json 文件
- 💾 **保存**：保存配置到文件
- ➕ **新增**：添加根菜单项
- 📑 **添加子项**：为选中项添加子菜单
- ➖ **分隔线**：添加菜单分隔线
- 🗑️ **删除**：删除选中的菜单项
- ⬆️ **上移** / ⬇️ **下移**：调整菜单项顺序

### 左侧面板 - 菜单结构
显示所有菜单项的树形结构，支持：
- 查看菜单层级关系
- 选择要编辑的菜单项
- 查看菜单项状态（分隔线、隐藏等）

### 右侧面板 - 详细配置
分为多个可折叠区域：

#### 📌 基本信息
- **菜单文本**：显示在右键菜单中的文字（支持动态变量）
- **是否为分隔线**：设置为菜单分隔线
- **是否可见**：控制菜单项的显示/隐藏
- **排序序号**：菜单项的排序值

#### 📍 显示位置
- **显示在根菜单**：直接显示在右键菜单根部
- **显示在文件上**：右键点击文件时显示
- **显示在文件夹上**：右键点击文件夹时显示
- **显示在文件夹背景**：在文件夹空白处右键时显示

#### ⚙️ 程序设置
- **程序路径**：要执行的程序（支持预设命令如 `copypath`）
- **命令参数**：传递给程序的参数
- **图标路径**：菜单项图标（支持 .ico、.png、.exe 等）

#### 📄 文件类型过滤
- 指定适用的文件扩展名（如 `.txt, .doc`）
- 留空表示适用于所有文件

#### 🔧 高级选项
- **参数跟在每条路径后面**：控制参数的拼接方式
- **路径使用引号**：为文件路径添加双引号
- **只使用程序路径**：不传递文件路径，只运行程序
- **添加文件类型参数**：在末尾添加 `&file` 或 `&folder` 标识
- **显示完整路径和命令**：调试模式，执行前显示完整命令

#### 💻 CMD 设置
- **通过 CMD 运行程序**：使用 cmd.exe 执行命令
- **隐藏 CMD 窗口**：不显示命令行窗口
- **保持 CMD 窗口打开**：命令执行后保持窗口（/K 参数）

## 动态变量

在"菜单文本"中可以使用以下动态变量：

- `${filename}` - 文件名（无扩展名）
- `${filename-single}` - 第一个文件名
- `${extension}` - 文件扩展名
- `${extension-single}` - 第一个文件的扩展名
- `${parentdir}` - 父目录路径
- `${parentdir-single}` - 第一个文件的父目录
- `${fullpath}` - 完整路径
- `${fullpath-single}` - 第一个文件的完整路径

示例：`复制 ${filename} 到剪贴板`

## 预设命令

在"程序路径"中可以使用预设命令：

- `copypath` - 复制路径到剪贴板
- `openfolderandselectitems` - 打开文件夹并选中项目
- `messagebox.show` - 显示消息框

## 使用流程

1. **打开配置**：
   - 点击"打开"按钮选择 `MenuConfig.json`
   - 或将配置文件放在程序同目录，自动加载

2. **编辑菜单**：
   - 点击"新增"添加新菜单项
   - 在左侧树中选择要编辑的项
   - 在右侧面板修改配置
   - 使用"添加子项"创建子菜单

3. **调整顺序**：
   - 选中要移动的菜单项
   - 点击"上移"或"下移"按钮

4. **保存配置**：
   - 点击"保存"按钮
   - 配置会保存为格式化的 JSON 文件

5. **应用配置**：
   - 将生成的 `MenuConfig.json` 放到右键菜单 DLL 所在目录
   - 重新注册 SharpShell 扩展或重启资源管理器

## 快捷操作

- **复制菜单配置**：先创建一个模板项，编辑后可在 JSON 中复制
- **批量编辑**：直接在 JSON 中编辑，然后用此工具验证和调整
- **测试配置**：使用"显示完整路径和命令"选项测试命令是否正确

## 注意事项

1. 保存前请确保所有必填字段已填写
2. 文件路径建议使用绝对路径或环境变量
3. 修改配置后需要重新注册 SharpShell 扩展才能生效
4. 建议在修改前备份原配置文件

## 技术细节

- **开发框架**：WPF (.NET Framework 4.8)
- **数据绑定**：MVVM 架构
- **JSON 处理**：Newtonsoft.Json 13.0.3
- **配置格式**：与 SharpShell MenuFunctions 项目兼容
