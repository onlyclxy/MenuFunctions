### 2. 🎯 完整的拖拽排序

#### 功能特性：
✅ **拖拽操作**
- 点击并拖动菜单项
- 实时跟随鼠标
- 流畅的拖拽体验

✅ **可视化指示器**（高级）
- 拖拽到项目上方 → 插入到前面
- 拖拽到项目中间 → 作为子项
- 拖拽到项目下方 → 插入到后面
- 蓝色横线指示拖放位置
- 缩进显示层级关系

✅ **智能排序**
- 自动更新 Order 字段
- 保持菜单顺序一致
- 支持跨层级拖拽

✅ **拖拽限制**
- 不能拖拽到自身
- 保护菜单结构完整性

#### 使用方法：
1. **普通拖拽**：
   - 点击菜单项不放
   - 拖动到目标位置
   - 松开鼠标完成

2. **精确定位**：
   - 拖到项目上方1/4 → 前面插入
   - 拖到项目中间 → 添加为子项
   - 拖到项目下方1/4 → 后面插入

3. **配合按钮**：
   - 拖拽 + ⬆️上移/⬇️下移 = 灵活调整

   - 验证功能是否正确

## 🎯 工作流程示例

### 场景1：创建并测试新菜单

```
步骤1：创建菜单
1. 点击"➕ 新增菜单项"
2. 菜单文本："用VSCode打开"
3. 程序路径："C:\Program Files\Microsoft VS Code\Code.exe"
4. 文件类型：.txt, .js, .py, .html

步骤2：选择测试文件
1. 在文件浏览器中导航到测试文件夹
2. 点击一个 .js 文件

步骤3：测试运行
1. 选中"用VSCode打开"菜单项
2. 点击"▶️ 测试运行"
3. 确认并执行

步骤4：保存
1. Ctrl+S 保存配置
```

### 场景2：重新组织菜单结构（拖拽）

```
步骤1：创建分组
1. 新增菜单项："文本编辑器"
2. 不设置程序路径（作为分组容器）

步骤2：拖拽重组
1. 拖动"用记事本打开"到"文本编辑器"中间
   → 成为子菜单
2. 拖动"用VSCode打开"到"用记事本打开"下方
   → 插入为第二个子项
3. 拖动"用写字板打开"
   → 继续添加

步骤3：调整顺序
1. 在子菜单中拖拽调整顺序
2. 或使用"⬆️上移"/"⬇️下移"
```

### 场景3：批量复制创建

```
目标：为不同文件类型创建相似菜单

步骤1：创建模板
1. 创建"打开方式"菜单
2. 配置好所有选项

步骤2：批量复制
1. Ctrl+C 复制模板
2. Ctrl+V 粘贴
3. 修改文本和程序路径
4. 重复创建多个

步骤3：分类整理
1. 使用拖拽将相关项归类
2. 创建子菜单分组
```
